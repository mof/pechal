The Datadog API Collection contains requests for the full range of Datadog APIs, including Metrics, Monitors, Dashboards, Logs, Synthetics, Security Monitoring, Cloud Cost Management, and more. Use it to explore endpoints, prototype integrations, and automate tasks on the Datadog platform.

#### **Authentication**

Authentication uses [Collection variables](https://learning.postman.com/docs/sending-requests/variables/variables/#defining-collection-variables). No separate environment setup is required.

1. In Datadog, retrieve or create an API key and application key from [Organization Settings](https://app.datadoghq.com/organization-settings/api-keys), or through the [Datadog API](https://docs.datadoghq.com/api/latest/key-management/).
    
2. Select the Datadog API Collection in Postman and click the Variables tab.
    
3. Enter your key values in the Value fields for `api_key` and `application_key`.

#### **Site configuration**

If your Datadog account is not on the US1 site (`datadoghq.com`), deselect the `datadoghq.com` site variable and select the correct variable for your region. See [Getting started with Datadog Sites](https://docs.datadoghq.com/getting_started/site/) to identify your site.

For the full API reference, see the [Datadog API documentation](https://docs.datadoghq.com/api/latest/).
